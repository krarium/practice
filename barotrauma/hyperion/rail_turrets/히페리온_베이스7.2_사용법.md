# 히페리온 베이스 7.2 — 레일 이탈 수정·레일 연장·해치 차수막·조명

7.1(다른 세션 제작)을 기준으로 고친 버전입니다. 7.1 생성 스크립트를 그대로 다시 돌려 7.1과 똑같은 파일이 나오는 것을 먼저 확인했습니다. 그다음 아래 항목만 바꿔 7.2를 생성했습니다. 회로 구조(전개/수납, 잠망경, 해치 순서, 정전 복귀)는 7.1과 같습니다. **C# 추가나 수정은 없습니다.**

## 설치

1. 게임을 끄고 `LocalMods/Hyperion_RailTurrets` 폴더를 ZIP 안의 같은 폴더로 **통째로 교체**합니다. 7.1 `.sub`가 남으면 안 됩니다. 7.2에서는 `RailPorts.xml`도 바뀌었습니다.
2. 잠수함 에디터에서 **히페리온 - 베이스 7.2**를 새로 엽니다. 7.1이나 그 저장본으로 시험하지 않습니다.

## 고친 것

### 1. 잠망경 기본 화면 = 이중 코일건
잠망경은 조준 신호가 마지막으로 도착한 포탑을 카메라와 하단 잔탄 화면으로 씁니다(게임 소스 `Controller.GetFocusTarget`). 7.1에서는 레일건이 마지막이었습니다. 이동포탑 안 조준 수신기 배선 순서를 `레일건 → 이중 코일건`으로 바꿔서, 이중 코일건 화면이 기본으로 나옵니다.

### 2. 격납고 해치 차수막(함체 글리치)
상부·하부 격납고 커스텀 해치 바깥면에 10px 두께의 얇은 헐을 하나씩 넣었습니다(`상부/하부 이동포탑 해치 차수막`). 이제 해치 갭은 `격납고 ↔ 차수막 헐`을 잇고, 바다에 열린 쪽이 없습니다. 그래서 해치가 열려도 물이 들어오지 않습니다. 차수막 헐 자체에는 바다와 이어진 갭이 없습니다.

### 3. 레일 이탈 (원인과 수정)
게임 소스(`DockingPort`, `SubmarineBody`, Farseer `WeldJoint`)로 확인한 원인입니다.

- **잠긴 상태는 단단합니다.** 도킹 잠금은 WeldJoint입니다. 이 조인트의 1Hz 완충은 회전에만 걸리고, 잠수함 몸체는 회전이 고정되어 있습니다. 그래서 잠긴 포탑은 충격이나 빠른 이동에도 위치가 고정됩니다. 이탈은 **한 칸씩 옮겨 가는 순간**에만 생길 수 있습니다.
- **7.1의 위치 오류:** 레일 앵커는 "왼쪽 방향 도킹"이라 상대 포트가 앵커 **왼쪽** 94.6px에 붙습니다. 7.1은 오른쪽에 붙는다고 보고 앵커를 반대로 옮겼습니다. 그 결과 실제 포탑 몸체가 계획 경로보다 약 189px 왼쪽으로 다녔습니다. 상부 사선이 A층에 걸린 것도 이 때문입니다.
- **이동 순간의 충돌:** 칸을 옮기는 동안의 도킹 당김(DistanceJoint)은 충돌이 켜져 있습니다. 포탑 서브의 유일한 충돌체는 16px 헐인데, 이것이 격납고 안이나 외벽, A층 모서리에서 히페리온 헐과 벽에 겹치며 밀려났습니다. 포착 범위(바닐라 추정 200×64px)를 벗어나면 다시 붙지 못합니다. 떨어진 포탑 서브는 마른 헐 때문에 떠오릅니다. 상부 포탑이 위로 사라지고, 하부 포탑이 선체 아래에 끼던 현상과 맞습니다.
- **사다리가 걸리던 원인도 같습니다.** 포탑 헐이 포트 바로 옆에 있으면 게임이 도킹 연결부에 헐과 막는 몸체(CreateHulls)를 만듭니다. 7.1에서는 그 몸체가 하부 격납고 사다리를 가로질렀습니다.

수정 내용:

| 항목 | 7.1 | 7.2 |
|---|---|---|
| 레일 포트 프리팹 `DockedDistance` | 바닐라(172×배율) | **0**: 포탑이 앵커 위치에 정확히 붙음 |
| 레일 포트 프리팹 `DistanceTolerance` | 바닐라 | **256×256**: 한 칸은 최대 76px라 밀려나도 다시 잡음 |
| 포탑 서브 충돌체(헐) 위치 | 도킹 포트 위치 | 상부 포탑 **400px 위**, 하부 포탑 **300px 아래** |
| 이동 중 히페리온과 충돌 | 격납고·외벽·A층에서 겹침 | 238개 모든 위치에서 겹치는 헐·벽·문 0 |
| 도킹 연결부 막는 몸체 | 생성됨 | 생성 안 됨(포트 옆에 포탑 헐이 없음) |

말씀하신 "같은 벽끼리만 막는 특수 벽"은 충돌 분류가 C# 코드에 고정되어 있어 XML로는 만들 수 없습니다. 위 방법으로 원인을 직접 없앴으므로 쓰지 않았습니다.

### 4. 하부 격납고 사다리
막는 몸체 자체가 이제 생기지 않습니다. 요청대로 사다리도 오른쪽으로 24px 옮겼습니다(x 456~467). 천장 해치(368~496)와 배경판(406~470) 안에 그대로 있습니다.

### 5. 조명 = 오르카 수준
오르카 천장 조명은 범위 300~600(평균 약 420), 밝기(알파) 80~130이고 그림자를 씁니다. 히페리온 천장 형광등 64개는 범위 700, 밝기 255에 그림자가 없었습니다. 이를 **범위 420, 밝기 115, 그림자 켬**으로 바꿨습니다. 색은 그대로입니다. 장식 조명(lightcomponent90) 3개도 밝기를 255에서 120으로 낮췄습니다. 그림자 조명은 66개로 에디터 한도 100 이내입니다.

### 6. 레일 경로와 360도 회전
- **상부 레일:**
  - x −4020부터 3660까지입니다.
  - A층 위는 y 1156입니다. 사선은 A층 테일핀 F3 오른쪽인 x −1300에서 시작해 x −1000에서 B층 높이 y 900에 닿습니다.
  - 왼쪽 끝은 모든 외장보다 바깥이라 수직으로 아래를 쏠 수 있습니다. 오른쪽 끝은 구형 테일핀A(x 3554)와 테일핀 E P1(x 3612)보다 오른쪽입니다.
- **하부 레일:** 같은 x −4020~3660, y −1120 직선입니다.
- **칸 수:** 상부 레일 106칸, 하부 레일 104칸입니다. 격납고 경로는 각 14칸으로 그대로입니다.
- **포탑 방향:**
  - 상부 포탑은 갑판 위에 선 방향(기본 회전 0)입니다. 7.1에서는 기본 회전 180이 남아 거꾸로였습니다.
  - 하부 포탑은 매달린 방향(180)입니다.
  - 두 포탑 모두 회전 범위 0~360으로 한 바퀴 다 돕니다.

## 확인한 것 (게임 실행 없이)

- 규칙 검사: 배선 1811개(대각선·노출·끊김·무효 전원 0), 게이트 1207개 규칙 통과, 웨이포인트 한 덩어리.
- 위치 검사(`check72_geometry.py`): 앵커가 경로점과 일치하고, 한 칸은 최대 76px입니다. 포탑 충돌체는 238개 위치 모두에서 히페리온과 겹치지 않습니다. 해치 4개는 모두 `격납고 ↔ 차수막`으로 연결되고, 사다리 위치와 조명 값도 맞습니다.
- 회로 모델(`verify_hyperion72.py`): 잠금 0.35초와 1초 두 조건에서 7.1과 같은 시나리오를 모두 통과했습니다. 정적 확인은 19923건입니다.
- 에디터 재저장 3회 모델: ID 중복 0, 장전기 링크 4개 유지.
